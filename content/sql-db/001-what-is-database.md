# データベースとは何か

## 今日学ぶこと

- データベースの役割
- テーブルとは何か
- レコードとは何か
- SQLとは何か

## データベースは情報を保存する場所

データベースは、アプリで使う情報を保存する場所です。

ユーザー、商品、注文、学習進捗など、後でまた使いたい情報を保存します。

## テーブル

テーブルは、同じ種類のデータをまとめる表です。

たとえばユーザー情報を保存する `users` テーブルには、メールアドレス、名前、パスワードのハッシュなどが入ります。

## レコード

レコードは、テーブルの中の1行分のデータです。

ユーザーが3人いれば、`users` テーブルには3件のレコードがあります。

## SQL

SQLは、データベースにお願いをするための言葉です。

たとえばデータを取得するときは `SELECT` を使います。

```sql
SELECT * FROM users;
```

これは「usersテーブルのデータを取得して」という意味です。

## 実際の開発では

バックエンドはデータベースに直接SQLを送ることもありますが、SQLAlchemyのようなライブラリを通して操作することも多いです。

それでもSQLの基本を知っていると、データ調査や不具合調査がかなり楽になります。

## まとめ

- データベースは情報を保存する場所です。
- テーブルは同じ種類のデータをまとめる表です。
- レコードはテーブルの1行です。
- SQLはデータベースにお願いをする言葉です。
