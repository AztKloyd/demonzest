# 問題

2つの整数 `A` と `B` が与えられます。
`A + B` の結果を出力してください。

## 入力

1行に2つの整数 `A` と `B` が空白区切りで与えられます。

## 出力

`A + B` の結果を1行で出力してください。

## 制約

- `0 <= A <= 100`
- `0 <= B <= 100`

## 考え方

プログラムは、まず入力を読む必要があります。
そのあと、2つの値を数値として足して、結果を表示します。
