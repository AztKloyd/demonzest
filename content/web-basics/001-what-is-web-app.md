# Webアプリとは何か

## 今日学ぶこと

- Webアプリとは何か
- ブラウザ、サーバー、データベースの役割
- 画面にデータが表示されるまでの流れ

## まず一言でいうと

Webアプリとは、ブラウザを使ってインターネット上で動かすアプリです。

たとえば、Gmail、Notion、GitHub、社内の勤怠システムなどは Webアプリです。

## やさしい例え

Webアプリは、レストランに少し似ています。

ユーザーはブラウザから注文します。
サーバーはその注文を受けて、必要な情報を用意します。
データベースは、メニューや注文履歴を保存している場所です。

ユーザーはキッチンの中を直接見ません。
でも、注文すると料理が返ってきます。

Webアプリでも同じように、ユーザーはサーバーやデータベースを直接見ません。
でも、画面から操作すると、必要な結果が返ってきます。

## 基本の説明

Webアプリには、主に3つの大事な部分があります。

| 名前 | やさしい意味 | 例 |
|---|---|---|
| ブラウザ | ユーザーが見る画面を表示するもの | Chrome、Safari、Edge |
| サーバー | リクエストを受けて処理する場所 | ログイン処理、データ取得 |
| データベース | データを保存する場所 | ユーザー情報、商品情報 |

ユーザーが画面でボタンを押すと、ブラウザはサーバーにお願いを送ります。
サーバーは必要ならデータベースを見て、結果をブラウザに返します。
ブラウザはその結果を画面に表示します。

## 実際の開発では

開発現場では、画面側を作る人をフロントエンドエンジニアと呼ぶことがあります。
サーバー側を作る人をバックエンドエンジニアと呼ぶことがあります。

ただし、実際の仕事では完全に分かれていないこともあります。
フロントエンドの人がAPIを確認することもあります。
バックエンドの人が画面の動きを確認することもあります。

## よく使う言葉

| 言葉 | やさしい意味 | 現場での例 |
|---|---|---|
| 画面 | ユーザーが見る部分 | 一覧画面を修正します |
| 実装 | 機能を作ること | ログイン機能を実装します |
| 仕様 | 作るもののルール | 仕様を確認します |
| データ | 保存したり表示したりする情報 | ユーザー情報を取得します |
| リクエスト | ブラウザからサーバーへのお願い | APIにリクエストを送ります |
| レスポンス | サーバーからブラウザへの返事 | レスポンスを画面に表示します |

## よくある勘違い

Webアプリは、画面だけで動いているわけではありません。

画面の後ろには、サーバーやデータベースがあります。
見えない部分も含めて、1つのアプリとして動いています。

## まとめ

- Webアプリは、ブラウザを使って利用するアプリです。
- ブラウザ、サーバー、データベースが協力して動きます。
- 開発現場では、リクエスト、レスポンス、実装、仕様という言葉をよく使います。
